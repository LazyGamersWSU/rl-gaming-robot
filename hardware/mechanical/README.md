# Mechanical

Mechanical components for mounting and positioning the solenoid actuators over the game controller. A .f3d file is a proprietary Autodesk Fusion 360 archive that stores a complete parametric 3D CAD design. This means that these files must be opened with Autodesk Fusion 360.

## CAD Files

- `Actuator Plate.f3d` — Mounting plate for the solenoid actuators; actuators are friction fit into sleeves
- `Gantry Support.f3d` — Frame for holding the actuator plate above the cradle 
- `SNES Cradle.f3d` — Holds the game controller in place
- `Solenoid Sleeve.f3d` — Test sleeve for positioning and guiding the solenoid
- `snes_overlay.jpg` — Controller reference image used during CAD design
